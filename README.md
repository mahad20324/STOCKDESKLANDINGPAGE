# StockDesk Inventory — Landing Page

Marketing site for **StockDesk Inventory**, inventory and POS control for busy counters. Starting in Uganda, priced in UGX, with MTN MoMo and Airtel Money billing.

Live product app: [app.stockdeskinventory.com](https://app.stockdeskinventory.com)

## Pages

| File | Description |
|------|-------------|
| `stockdeskinventory/index.html` | Home — product, proof, FAQ, founders, CTA |
| `stockdeskinventory/pricing.html` | Plans (Starter / Growth / Business) |
| `stockdeskinventory/privacy.html` | Privacy policy |
| `stockdeskinventory/terms.html` | Terms of service |

Shared assets: `styles.css`, `app.js`, `public/` (logo, screenshots, partner mark).

## Stack

- Static HTML, CSS, and vanilla JavaScript
- No build step or package manager required
- Fonts loaded from Google Fonts (Space Grotesk, Inter, IBM Plex Mono)

## Run locally

Open the site folder and serve it with any static server, for example:

```bash
# from the repo root
cd stockdeskinventory
npx serve .
```

Or open `stockdeskinventory/index.html` directly in a browser.
